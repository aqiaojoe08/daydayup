Small userscripts I use every day. Install a userscript manager such as [Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/), then click **Install**. Installed scripts update automatically from `main`.

## GitHub HTML Preview (v1.5.0)

Jump both ways between a GitHub HTML file and its rendered copy. Adds a **Preview** button on the blob page (htmlpreview.github.io; Alt-click for raw.githack.com) and an **Edit on GitHub** button on the rendered page.

[Install](https://github.com/aqiaojoe08/daydayup/raw/refs/heads/main/github-html-preview.user.js) · [Source](https://github.com/aqiaojoe08/daydayup/blob/main/github-html-preview.user.js)

## StudyTube (v1.32.0)

A study dashboard on YouTube and Google: one sidebar with today's and tomorrow's calendar, keyword-filtered unread Gmail, and the last 7 days of AI-lab research news (Anthropic, OpenAI, DeepMind). On YouTube it also covers burned-in captions with a movable overlay, replaces the related-videos rail, and hides the Shorts shelf.

[Install](https://github.com/aqiaojoe08/daydayup/raw/refs/heads/main/studyhub.user.js) · [Source](https://github.com/aqiaojoe08/daydayup/blob/main/studyhub.user.js)
